# Backend امن شهر آینه — نسخهٔ ۷.۰.۰

## فرانت‌اند سه‌بعدی نسخهٔ ۷

فایل `public/index.html` همان بازی نسخهٔ ۷ است؛ موتور WebGL 1 داخلی و مدل‌های سه‌بعدی در خود HTML قرار دارند. هیچ فایل JavaScript سه‌بعدی از CDN بارگیری نمی‌شود. در صورت نبود WebGL، صفحه از رندر دوبعدی جایگزین استفاده می‌کند. برای مشاهدهٔ گرافیک و کنترل‌های موبایل، مستند `../docs/3D_MOBILE_RENDERING_V7.md` را ببینید.

این سرویس با Node.js و کتابخانه‌های داخلی ساخته شده و وابستگی npm ندارد. HTML از مسیر `/` سرو می‌شود و همان‌مبدأ با API ارتباط می‌گیرد.

## فایل‌های سرور

- `private-data/اطلاعات کاربران.txt`: رکوردهای پروفایل ثبت‌نام، رمزگذاری‌شده با AES-256-GCM، یک رکورد در هر خط.
- `private-data/نتایج بازی کاربران.txt`: نتایج مرحله‌ها با شناسهٔ مستعار؛ بدون نام، نام خانوادگی، شمارهٔ همراه یا تاریخ تولد.
- `private-data/sessions.json`: هش توکن نشست و وضعیت رضایت؛ این فایل نیز خصوصی است.

فایل‌ها متن سادهٔ قابل‌خواندن نیستند؛ خطوط رمزگذاری‌شده‌اند تا نسخهٔ پشتیبان یا افشای تصادفی فایل، اطلاعات را بی‌درنگ آشکار نکند. مسیر `private-data` را هرگز داخل `public` قرار ندهید، در Git ثبت نکنید یا از وب‌سرور استاتیک منتشر نکنید.

## اجرا در Windows PowerShell

1. Node.js نسخهٔ LTS را نصب کنید.
2. در همین پوشه یک کلید رمزنگاری بسازید:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

3. خروجی ۶۴ کاراکتری را در متغیر محیطی قرار دهید و سرور را اجرا کنید:

```powershell
$env:DATA_ENCRYPTION_KEY='کلید-۶۴-کاراکتری-اینجا'
$env:PORT='3000'
node server.js
```

4. مرورگر را به `http://localhost:3000` باز کنید. برای میزبانی عمومی، حتماً HTTPS را از طریق reverse proxy معتبر فعال کنید؛ این سرور به‌تنهایی TLS ارائه نمی‌کند.

## API

- `GET /api/health` — سلامت سرویس
- `POST /api/register` — ایجاد/به‌روزرسانی پروفایل و ثبت وضعیت رضایت
- `POST /api/activity` — به‌روزرسانی زمان آخرین استفادهٔ حساب؛ بدون شناسه یا جزئیات مرحله
- `POST /api/results` — ذخیرهٔ نتیجهٔ مرحله فقط با رضایت پژوهشی فعال
- `DELETE /api/account` — حذف رکوردهای پروفایل و نتایج همان حساب

لغو رضایت پژوهشی با ویرایش فرم و برداشتن تیک انجام می‌شود؛ ثبت دوبارهٔ پروفایل بدون رضایت، داده‌های پژوهشی قبلی همان شناسه را از فایل نتایج حذف می‌کند.

## خروجی مدیر

روی سرور مورد اعتماد و فقط با کلید رمزنگاری اصلی:

```powershell
node export-data.js profiles
node export-data.js research
```

خروجی پروفایل، حاوی اطلاعات شناسایی‌کننده است و فقط برای مدیر مجاز ساخته می‌شود. خروجی پژوهشی به‌صورت تجمیعی است و نام/شماره/تاریخ تولد ندارد. پوشهٔ `private-data/exports` را نیز محرمانه نگه دارید.

## محدودیت‌ها و الزامات پیش از انتشار عمومی

- شمارهٔ موبایل در این نسخه OTP نمی‌شود؛ هویت یا مالکیت شماره اثبات نشده است.
- نشست به مرورگر/دستگاه فعلی وابسته است؛ بازیابی حساب روی دستگاه دیگر هنوز نیازمند احراز هویت واقعی است.
- فرم ثبت‌نام همهٔ فیلدهایی را که صاحب پروژه خواسته اجباری می‌کند؛ پیش از انتشار عمومی باید ضرورت جمع‌آوری هر فیلد، مبنای قانونی، هویت و تماس مسئول داده، میزبان/کشور محل داده، مدت نگهداری و رویهٔ دسترسی/اصلاح/حذف را نهایی کنید.
- رضایت پژوهشی جدا، اختیاری و بدون پیش‌علامت است. افراد زیر ۱۸ سال در این نسخه به پژوهش وارد نمی‌شوند؛ پژوهش با افراد زیر سن قانونی به سازوکار رضایت سرپرست و بررسی اخلاق مستقل نیاز دارد.
- داده‌های پژوهشی با شناسهٔ مستعار ثبت می‌شوند؛ این داده‌ها «ناشناس مطلق» نیستند. فایل اطلاعات کاربران با هویت مستقیم، جداگانه و رمزگذاری‌شده نگهداری می‌شود.
- پیش از انتشار در EU، اطلاعیهٔ حریم خصوصی و فرایندهای GDPR را با مشاور/مسئول حفاظت داده بررسی کنید.

## اصلاحیهٔ ۶.۰.۱

عنوان شغل پس از NFC-normalize فقط از ابتدا و انتها trim می‌شود؛ فاصله‌های میان کلمات حفظ می‌شوند. نسخهٔ HTML میزبانی‌شده نیز اصلاح شده است تا Space در ورودی‌ها به کنترل بازی تبدیل نشود.
