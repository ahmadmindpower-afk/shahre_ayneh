# گزارش آزمون نسخهٔ ۶ — شهر آینه

تاریخ ساخت: ۱ نوامبر ۲۰۲۶

## قابلیت‌های فرم و بازی

- فرم ثبت‌نام در اولین اجرا نمایش داده شد و بدون تکمیل فیلدهای اجباری، ورود به بازی ممکن نبود.
- فیلدهای نام، نام خانوادگی، جنسیت، شمارهٔ همراه، تاریخ تولد، تحصیلات و شغل ذخیره و دوباره خوانده شدند.
- تقویم شمسی در Chromium آزموده شد؛ ۱۳۷۰/۰۱/۰۱ به ۱۹۹۱-۰۳-۲۱ تبدیل شد. سرور نیز مطابقت تاریخ شمسی و میلادی را دوباره بررسی می‌کند.
- شمارهٔ همراه نامعتبر رد شد.
- انتخاب تاریخ برای فرد زیر ۱۸ سال، رضایت پژوهشی را غیرفعال کرد؛ API نیز ثبت پژوهشی افراد زیر ۱۸ سال را رد کرد.
- نام واردشده جایگزین نام نمایشی «روشا» شد؛ متن‌های افزوده‌شدهٔ پویا نیز بررسی شدند.
- در نمای موبایل با عرض ۳۹۰ پیکسل، سرریز افقی مشاهده نشد.
- مرورگر هیچ خطای JavaScript یا خطای کنسولی گزارش نکرد.

## کاتالوگ بازی

- ۳۸۹ مرحله، ۲۵۹ الگوی یکتا، ۲۲ تعارض و ۱۸ شهر در ۳ قلمرو.
- ۳۸۳ پرونده و ۶ مرحلهٔ ویژه.
- ۲۵۹ مرحلهٔ اصلی تک‌الگویی بدون تکرار شناسه.
- ۱۰۲ مرحلهٔ ترکیبی بدون امضای ترکیب تکراری.
- گزینه‌های پرونده‌ها: سه گزینه و دقیقاً یک پاسخ تعریف‌شده در آزمون کاتالوگ.
- آزمون هم‌ترازی داده‌ها: ۳۸۹ مرحلهٔ مورد انتظار و ۳۸۹ مرحلهٔ اعمال‌شده، صفر ناهماهنگی.
- آزمون جهان شهری: همهٔ ۳۸۹ مرحله به یکی از ۱۸ شهر متصل‌اند؛ ۱۸ تصویر شهر موجود و معتبرند.

## بک‌اند و داده‌ها

- سلامت سرور و سرو صفحهٔ بازی آزموده شد.
- پروفایل در `اطلاعات کاربران.txt` با AES-256-GCM رمزگذاری شد؛ متن خام نام و تلفن در فایل رمزگذاری‌شده دیده نشد.
- نتایج در `نتایج بازی کاربران.txt` با شناسهٔ مستعار ذخیره شدند و هیچ نام، تلفن یا تاریخ تولدی در رکورد نتیجه وجود نداشت.
- به‌روزرسانی پروفایل، رکورد تکراری ایجاد نکرد.
- زمان آخرین استفاده به‌صورت مستقل و بدون شناسه یا محتوای مرحله به‌روزرسانی شد.
- خروجی مدیر برای پروفایل و گزارش تجمیعی پژوهش ایجاد شد؛ گزارش تجمیعی، دسته‌بندی شغل را هم پوشش می‌دهد.
- لغو رضایت پژوهشی، نتایج قبلی همان شناسه را از فایل نتایج حذف کرد و ارسال نتایج بعدی را مسدود کرد.
- حذف حساب، رکورد پروفایل، نتایج و نشست همان شناسه را حذف کرد.
- سرور با کلید رمزنگاری اشتباه اجرا نشد و فایل‌های موجود را تغییر نداد.
- نحو JavaScript بازی و فایل‌های Node.js بررسی شد.

## محدودیت‌ها

- آزمون‌ها فنی و با داده‌های ساختگی در مسیر موقت بودند؛ هیچ دادهٔ واقعی کاربر در بسته قرار ندارد.
- سرور هنوز روی دامنهٔ عمومی یا میزبان ابری مستقر نشده است.
- شمارهٔ تلفن OTP نمی‌شود؛ مالکیت شماره تأیید نمی‌شود و بازیابی حساب بین دستگاه‌ها آماده نیست.
- بازی‌آزمایی انسانی تک‌تک ۳۸۹ مرحله انجام نشده است.
- پیش از انتشار عمومی، مسئول داده، مبنای قانونی جمع‌آوری هر فیلد، مدت نگهداری، محل میزبانی، اطلاعیهٔ حریم خصوصی و فرایند رسیدگی به درخواست‌های افراد باید تکمیل و بررسی حقوقی شوند.

## نحوهٔ تفسیر ذخیره‌سازی

در حالت HTML مستقل، پروفایل در حافظهٔ محلی همان مرورگر ذخیره می‌شود و فایل سرور ایجاد نمی‌شود. برای تولید دو فایل TXT روی سرور، باید Node.js backend همراه بسته اجرا شود. رضایت پژوهشی جداگانه، اختیاری و بدون تیک اولیه است؛ بدون آن، پروفایل حساب ذخیره می‌شود اما نتیجهٔ مرحله به فایل پژوهشی افزوده نمی‌شود.

## Hotfix 6.0.1 — Occupation field whitespace regression

- Root cause: global game `keydown` handler called `preventDefault()` for Space and triggered the game interaction even while a text input had focus.
- Fixed in both `index.html` and `server/public/index.html` by yielding keyboard events to native controls.
- Browser keyboard test: `مهندس` + actual Space key + `نرم افزار` resulted in `مهندس نرم افزار`; first and last name fields also accepted spaces. Space outside form controls still triggered a game interaction.
- Server integration test: profile API accepted the multi-word occupation and the decrypted encrypted TXT record contained `مهندس نرم افزار`; only leading/trailing spaces were trimmed.
- JavaScript syntax, runtime catalogue, city mapping and static regression checks passed.
