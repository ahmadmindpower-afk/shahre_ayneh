# تحویل نسخهٔ جاری به مخزن GitHub `shahre_ayneh`

## وضعیت بستهٔ محلی — ۳۱ اکتبر ۲۰۲۶

این پوشه بستهٔ کامل نسخهٔ ۴ بازی شهر آینه است: ۲۲ تعارض، ۲۵۹ الگوی یکتا، ۳۸۹ مرحله (۳۸۳ پرونده و ۶ مرحلهٔ داستانی)، شش شهر، منابع ورودی و اسناد ممیزی.

**محدودیت اتصال:** در آخرین بررسی اتصال GitHub، مخزن مستقل `moshaveranzendegi-rgb/shahre_ayneh` در فهرست مخازن متصل قابل مشاهده نبود و پاسخ lookup آن 404 بود. بنابراین این بسته به GitHub push نشده است. برای جلوگیری از نوشتن در مخزن اشتباه، روی مخزن `one` تغییری انجام نشده است.

## محتوای اصلی
- `index.html` — بازی مستقل و آفلاین؛ با Chrome یا Edge باز شود.
- `data/conflict-master-catalogue.json` — ۲۲ تعارض یکتا.
- `data/pattern-catalogue.json` — ۲۵۹ الگوی یکتا.
- `data/stage-scene-catalogue.json` — ۳۸۹ مرحلهٔ کامل.
- `data/stage-review-v4.json` و `docs/STAGE_REVIEW_V4.md` — ممیزی محتوایی و تصمیم‌های ادغام/تفکیک.
- `source/` — دو PDF مرجع ورودی.
- `tests/` و `RUN_TESTS.bat` — آزمون ایستا و آزمون کاتالوگ.

## آزمون اجرا
در ریشهٔ پوشه اجرا کنید:

```bash
python tests/static_check.py
python tests/runtime_catalogue_check.py
```

نتیجهٔ آزمون در این ساخت: ۳۸۹ مرحله بارگذاری‌شده در Chromium headless، صفر خطای صفحه/کنسول؛ آزمون مهاجرت ذخیرهٔ نسخهٔ ۳ به ۴ نیز موفق بود. این آزمون‌ها جایگزین بازی‌آزمایی انسانی، صفحه‌خوان و دستگاه‌های واقعی نیستند.

## انتقال به مخزن مستقل
پس از اضافه‌کردن دسترسی مخزن `shahre_ayneh` در تنظیمات اتصال GitHub، محتویات این پوشه را به ریشهٔ مخزن مستقل منتقل کنید. شاخهٔ قدیمی `project/shahr-e-ayeneh` در مخزن `one` فقط اسکلت قدیمی است؛ آن را بدون مقایسه با این نسخه ادغام نکنید.
