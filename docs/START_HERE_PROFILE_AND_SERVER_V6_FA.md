# شروع سریع شهر آینه — نسخهٔ ۷.۰.۰ (سه‌بعدی موبایل‌محور)

## اجرای نسخهٔ سه‌بعدی روی موبایل و دسکتاپ

فایل `index.html` نسخهٔ ۷ دارای موتور داخلی WebGL 1 است و کتابخانهٔ سه‌بعدی یا CDN خارجی بارگیری نمی‌کند. روی گوشی، در مرورگر مدرن بازش کن؛ برای اجرای پایدارتر و ذخیرهٔ سروری، از دامنهٔ HTTPS استفاده کن. روی بازی با انگشت بکش تا دوربین بچرخد. در تنظیمات، کیفیت «خودکار» یا «صرفه‌جویی باتری» را برای گوشی‌های معمولی انتخاب کن. اگر WebGL پشتیبانی نشود، نسخهٔ دوبعدی جایگزین فعال می‌شود.

## اجرای آفلاین

فایل `index.html` را با Chrome یا Edge باز کنید. فرم ثبت‌نام در اولین اجرا نمایش داده می‌شود و تا تکمیل فیلدهای اجباری اجازهٔ ورود نمی‌دهد. تاریخ تولد فقط از تقویم شمسی انتخاب می‌شود. اطلاعات پروفایل و پیشرفت در همان مرورگر ذخیره می‌شوند؛ این حالت فایل سروری تولید نمی‌کند.

## اجرای همراه سرور

1. Node.js نسخهٔ LTS را روی سرور نصب کنید.
2. پوشهٔ `server` را روی سرور خصوصی کپی کنید.
3. در همان پوشه با `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` یک کلید ۶۴ رقمی hex بسازید.
4. کلید را در متغیر محیطی `DATA_ENCRYPTION_KEY` قرار دهید و `PORT=3000` را تنظیم کنید.
5. با `node server.js` سرور را اجرا کنید و دامنه را از طریق reverse proxy با HTTPS به آن متصل کنید.
6. پوشهٔ `private-data` را خارج از مسیر عمومی وب نگه دارید و از کلید رمزنگاری نسخهٔ پشتیبان امن تهیه کنید. بدون این کلید، فایل‌های رمزگذاری‌شده قابل بازیابی نیستند.

## فایل‌های سرور

پروفایل‌های سرور پس از حدود ۲۴ ماه (۷۲۰ روز) عدم فعالیت و نتایج پژوهشی پس از حدود ۲۴ ماه (۷۲۰ روز) از زمان ثبت، به‌طور خودکار منقضی و حذف می‌شوند. نسخهٔ آفلاین در localStorage می‌ماند تا کاربر آن را دستی حذف کند یا داده‌های مرورگر را پاک کند.

- `private-data/اطلاعات کاربران.txt`: پروفایل‌های رمزگذاری‌شده.
- `private-data/نتایج بازی کاربران.txt`: نتایج پژوهشیِ مستعار و رمزگذاری‌شده، فقط با رضایت مستقل.
- `private-data/sessions.json`: هش توکن نشست و زمان آخرین استفاده؛ بدون شناسه و پاسخ مرحله.

برای گزارش مدیر، در پوشهٔ server اجرا کنید: `node export-data.js profiles` یا `node export-data.js research`. خروجی پروفایل قابل‌شناسایی است و باید فقط در اختیار مدیر مجاز بماند. خروجی پژوهشی، تجمیعی است.

## محدودیت‌های قبل از انتشار

شمارهٔ همراه در این نسخه OTP نمی‌شود و بازیابی حساب روی دستگاه دیگر آماده نیست. فرم اجباری از فیلدهایی استفاده می‌کند که مالک پروژه خواسته است؛ پیش از انتشار عمومی باید ضرورت تک‌تک فیلدها، مسئول پردازش، مبنای قانونی، مدت نگهداری، محل میزبانی و حقوق کاربر مشخص و بررسی حقوقی شوند. رضایت پژوهشی اختیاری است و نباید شرط ورود به بازی باشد.

### اصلاح نسخهٔ ۶.۰.۱

فیلد شغل اکنون فاصلهٔ میان کلمات را می‌پذیرد. کنترل‌های صفحه‌کلید بازی هنگام تایپ در ورودی‌ها دخالت نمی‌کنند. سرور فاصلهٔ ابتدا و انتهای عنوان را تمیز می‌کند اما فاصله‌های داخل عنوان شغلی را حفظ می‌کند.

## اصلاحیهٔ نسخهٔ ۷

۱۸ شهر دارای نمای سه‌بعدی low-poly هستند. فرم ثبت‌نام اجباری، تقویم شمسی، ذخیرهٔ پروفایل و API سرور نسخهٔ ۶ حفظ شده‌اند. محدودیت‌های آزمون روی گوشی واقعی در `3D_MOBILE_RENDERING_V7.md` و `TEST_REPORT_V7.md` آمده‌اند.
