# شروع سریع شهر آینه — نسخهٔ ۷.۰.۰

## اجرای مستقل

فایل `index.html` را در Chrome یا Edge باز کنید. همهٔ ۱۸ پیش‌نمایش سه‌بعدی داخل فایل HTML تعبیه شده‌اند و موتور WebGL 1 داخلی است؛ بنابراین برای اجرای صحنهٔ سه‌بعدی، دریافت Three.js یا فایل از CDN لازم نیست. اگر دستگاه یا مرورگر WebGL نداشته باشد، نسخهٔ دوبعدی جایگزین فعال می‌شود.

## بازی با موبایل

1. برای تجربهٔ بهتر، فایل بازی را از یک میزبان HTTPS یا سرور بسته باز کنید.
2. پس از ثبت‌نام، بازی را شروع کنید.
3. برای چرخاندن زاویهٔ دید، انگشت را روی صحنهٔ سه‌بعدی بکشید.
4. با کنترل‌های روی صفحه حرکت کنید و دکمهٔ «تعامل» را برای گفت‌وگو، کشف سرنخ و حل معما به کار ببرید.
5. در تنظیمات، «خودکار» را برای شروع انتخاب کنید. در گوشی‌های ضعیف‌تر «صرفه‌جویی باتری» را فعال کنید؛ «جزئیات بیشتر» برای دستگاه‌های قوی‌تر است.

## نسخهٔ همراه سرور

برای ثبت پروفایل و نتایج پژوهشی روی سرور، از پوشهٔ `server` استفاده کنید و دستورهای `docs/START_HERE_PROFILE_AND_SERVER_V6_FA.md` و `server/README.md` را دنبال کنید. کلید رمزنگاری باید خصوصی بماند، `private-data` را در وب‌ریشه قرار ندهید و انتشار عمومی فقط با HTTPS انجام شود.

## ساختار بازی

- ۱۸ شهر سه‌بعدی در ۳ قلمرو داستانی
- ۳۸۹ مرحله، ۲۵۹ الگوی یکتا، ۲۲ تعارض
- فرم ثبت‌نام اجباری و تقویم شمسی
- ذخیرهٔ محلی پیشرفت و پشتیبانی از API سرور
- نسخهٔ دوبعدی پشتیبان برای دستگاه‌های فاقد WebGL

## تنظیم کیفیت

- خودکار: حالت پیشنهادی
- صرفه‌جویی باتری: وضوح/نرخ فریم پایین‌تر
- متعادل: تعادل کیفیت و عملکرد
- جزئیات بیشتر: برای دستگاه‌های قوی‌تر

## محدودیت آزمون

نسخه در Chromium دسکتاپ و emulation موبایل ۳۹۰×۸۴۴ با لمس و DPR=2 بررسی شده است. آزمایش روی گوشی فیزیکی، دمای دستگاه و مصرف باتری در مدل‌های مختلف هنوز لازم است. جزئیات در `TEST_REPORT_V7.md` آمده است.
